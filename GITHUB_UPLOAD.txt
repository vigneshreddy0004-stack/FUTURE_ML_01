# GitHub upload commands

Create a public repository named exactly:
FUTURE_ML_01

Then, inside this folder run:

git init
git add .
git commit -m "Complete Task 1 - Sales Demand Forecasting"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/FUTURE_ML_01.git
git push -u origin main

Replace YOUR_USERNAME with your GitHub username.
