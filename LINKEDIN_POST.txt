📊 Project: Sales & Demand Forecasting

I built a sales forecasting model using Python, Pandas, NumPy, Matplotlib and Scikit-learn.

Key work:

• Created time-based, lag and rolling features
• Trained a Random Forest regression model
• Evaluated the model using MAE, RMSE and MAPE
• Created business-friendly actual vs forecast visualizations
• Interpreted feature importance for business planning

This project helped me understand how machine learning can support inventory, staffing and promotion planning.
